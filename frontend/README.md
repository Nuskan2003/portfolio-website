# Nuskan Nazar Portfolio

A modern full-stack developer portfolio built with React, Tailwind CSS, Framer Motion, Node.js, Express.js, and MySQL.

## Features

* Modern responsive UI
* Dark & Light mode
* Glassmorphism Navbar
* Resume Download
* GitHub & LinkedIn Integration
* Project Showcase
* Detailed Case Studies
* Contact Form
* Mobile Responsive Design
* Smooth Animations

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* React Router DOM
* Framer Motion

### Backend

* Node.js
* Express.js

### Database

* MySQL

## Installation

```bash
npm install
npm run dev
```
